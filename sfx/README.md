# 음원 넣는 곳

누를 때 재생되는 소리입니다. 디자인마다 다른 소리를 씁니다.

```
crack1.mp3  crack2.mp3  crack3.mp3   왁스 코팅이 있는 디자인 (초코 · 청사과 · 버터 · 만두)
soap1.mp3   soap2.mp3   soap3.mp3    비누크런치
```

누를 때마다 해당 묶음에서 하나가 무작위로 재생되고,
길게 누르면 끝나는 대로 다음 클립이 이어집니다. 2~4초 길이가 적당합니다.

파일이 없어도 위젯은 소리 없이 정상 동작합니다. (`wakppu.log` 에 `audio error` 가 남습니다)
