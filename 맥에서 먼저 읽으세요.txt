왁뿌볼 — 맥에서 실행하기
=========================

"Apple은 ... 악성 코드가 없음을 확인할 수 없습니다" 라고 뜨나요?

  → 정상입니다. 바이러스가 아니라, 애플에 돈을 내고 등록한 앱이 아니라서
    맥이 무조건 한 번 막는 것입니다.

  → 그 창에서는 반드시 "완료" 를 누르세요.
    "휴지통으로 이동" 을 누르면 파일이 지워집니다.


풀어주는 방법 (1분, 한 번만 하면 됩니다)
----------------------------------------

1. 키보드에서 command 키와 스페이스바를 같이 누릅니다.

2. 검색창이 뜨면  터미널  이라고 치고 엔터를 누릅니다.
   까만 글씨창이 하나 열립니다.

3. 아래 한 줄을 그대로 복사해서 붙여넣고 엔터를 누릅니다.
   (직접 치지 말고 꼭 복사해서 붙여넣으세요)

xattr -cr ~/Downloads/왁뿌볼 ~/Desktop/왁뿌볼 2>/dev/null; echo 끝났습니다

4. "끝났습니다" 라고 나오면 성공입니다.

5. 이제 폴더 안의 "시작하기.command" 를 더블클릭하면 왁뿌볼이 뜹니다.


폴더가 다운로드나 바탕화면이 아닌 곳에 있다면
---------------------------------------------

  터미널에 아래를 치되, cd 다음에 반드시 띄어쓰기 한 칸을 넣고
  왁뿌볼 폴더를 창으로 끌어다 놓은 뒤 엔터를 누릅니다.

       cd 

  그 다음 아래를 치고 엔터. 마지막 점(.) 까지 그대로입니다.

       xattr -cr .


흔한 실수
---------

  xattr -cr/Users/이름/...      <- 이렇게 붙으면 안 됩니다
  xattr -cr /Users/이름/...     <- -cr 과 주소 사이에 반드시 한 칸

  "invalid option -- /" 라고 나오면 바로 이 띄어쓰기가 빠진 것입니다.


그래도 안 되면
--------------

  시스템 설정 → 개인정보 보호 및 보안 → 아래로 내리면
  "'시작하기.command' 은(는) 확인되지 않은 개발자가 배포했기 때문에 차단되었습니다"
  라는 줄이 있습니다. 옆의 "그래도 열기" 를 누르세요.


앱(.app) 으로 만들고 싶다면
---------------------------

  터미널에 아래를 차례로 칩니다. (3~5분 걸립니다)
  cd 다음에는 띄어쓰기 한 칸을 넣고 왁뿌볼 폴더를 끌어다 놓으세요.

       cd 

       pip3 install pywebview pyobjc-core pyobjc-framework-Cocoa pyobjc-framework-WebKit pyinstaller

       pyinstaller wakppu-mac.spec --noconfirm --clean

  다 되면 dist 폴더 안에 "왁뿌볼.app" 이 생깁니다.
  내 맥에서 직접 만든 앱은 경고 없이 바로 열립니다.
